# STM32 USB Device Library (Core)

Quelle: https://github.com/STMicroelectronics/stm32-mw-usb-device, Tag **v2.11.3**,
nur der Ordner `Core` ohne die `*_template`-Dateien, unveraendert.
Lizenz: siehe `LICENSE.md` (ST, BSD-3-Clause).

Die USB-MIDI-Klasse (`usbd_midi.c`), die Deskriptoren (`usbd_desc.c`) und die
Anbindung an den HAL-Treiber (`usbd_conf.c`) liegen im Projekt unter
`firmware/CM7/USB/`.
